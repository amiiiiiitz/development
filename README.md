# Dev Journey

A collection of software development projects, hands-on experiments, and technical learning focused on building practical applications and strengthening engineering skills.

## Overview

This repository serves as a central index of my development journey, organizing projects by development approach and purpose. It includes featured projects maintained in separate GitHub repositories and smaller learning projects organized within this repository.

## Project Categories

### AI-Assisted Development

Projects developed with the assistance of AI tools, including AI-powered applications, intelligent workflows, and practical experiments with modern development tools.

- **[Featured Projects](./ai-assisted/featured-projects/README.md)** — Selected projects maintained in separate repositories.
- **[Learning Projects](./ai-assisted/learning-projects/)** — Smaller applications, experiments, and practical learning exercises.

### Built from Scratch

Projects primarily implemented through my own coding and engineering work, emphasizing programming fundamentals, application development, and problem-solving.

- **[Featured Projects](./built-from-scratch/featured-projects/README.md)** — Selected projects maintained in separate repositories.
- **[Learning Projects](./built-from-scratch/learning-projects/)** — Practice projects, coding exercises, and smaller applications.

## Areas of Focus

- **Frontend Development:** Building interactive and responsive user interfaces.
- **Backend Engineering:** Developing APIs, server-side applications, and database-driven systems.
- **AI and Machine Learning:** Exploring machine learning concepts and practical AI applications.
- **AI Engineering:** Building LLM-powered applications using retrieval-augmented generation (RAG), AI agents, and related tools.
- **Software Development:** Strengthening programming fundamentals, problem-solving, and software engineering practices.

## Technologies

Technologies vary by project and may include:

- **Languages:** Python, JavaScript, C++
- **Frontend:** React, HTML, CSS, Tailwind CSS
- **Backend:** FastAPI, Node.js, Express
- **AI/ML:** NumPy, Pandas, PyTorch, and LLM-based tools
- **Tools:** Git, GitHub, Visual Studio Code

Not every technology listed is used in every project. Refer to each project's README for its specific technology stack and implementation details.
