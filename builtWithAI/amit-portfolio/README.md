## Design Approach

The portfolio uses a dark visual theme with restrained violet and cyan accents, distinct page layouts, and purposeful motion.

The main design priorities are:

- Clear content hierarchy and readable typography.
- Consistent navigation across multiple pages.
- Reusable components and maintainable frontend code.
- Responsive layouts for different screen sizes.
- Meaningful animations with consideration for reduced-motion preferences.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- npm, which is included with Node.js

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/amiiiiiitz/development.git
```

**2. Navigate to the portfolio directory**

If your portfolio is stored in the `build-with-AI-tools/amit-portfolio` directory:

```bash
cd development/build-with-AI-tools/amit-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### Production Build

Build the application for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
